## Descripción

Es un dispositivo interactivo de cuidado botánico diseñado para ayudar a las personas sobre el cuidado de sus plantas. Mediante un sistema de monitoreo en tiempo real integrado al sustrato, el dispositivo traduce el estado fisiológico y las necesidades de hidratación de la vegetación en un lenguaje sensorial intuitivo de luz y sonido. Cuando la planta experimenta falta de agua, el dispositivo emite señales que alertan al usuario antes de que aparezcan daños. Al eliminar las dudas sobre el momento y la cantidad exacta de riego, este dispositivo low-tech cierra la brecha de comunicación entre el usuario y la naturaleza, garantizando la salud, firmeza y vitalidad de nuestras plantas.
