## Descripción

Este proyecto nace a partir de una situación bastante cotidiana, cuando las personas se van de viaje o pasan varios días fuera de sus casas, es difícil saber en qué condiciones se encuentran sus plantas. Aunque se rieguen antes de salir, no es posible saber el estado de la tierra, si tiene poca humedad, si se mantiene un rango adecuado o si está recibiendo demasiada agua.
A partir de esta situación, queremos explorar la creación de un dispositivo de monitoreo que permita conocer el estado de humedad de la tierra cuando el usuario se encuentra fuera de casa.

## Desafío o problematica  inicial

Nuestro desafío surge de la dificultad del usuario para cuidar y monitorear las plantas cuando no se encuentra en casa, perdiendo la posibilidad de revisar directamente la tierra y saber si una planta necesita agua o tiene demasiada.
Nos interesa explorar cómo la tecnología puede ayudar a entregar esta información de una manera simple y fácil de interpretar, sin que el usuario tenga que estar físicamente junto a la planta.


## Objetivo 

Explorar y desarrollar un dispositivo Low Tech capaz de medir la humedad de la tierra de una planta comunicando su estado al usuario.
Buscamos experimentar con sensores de humedad, Arduino y otros componentes electrónicos para entender las posibilidades que tenga el  sistema y lograr definir una propuesta de dispositivo que sea simple, comprensible y útil para personas que se ausentan de sus casas. 


## Usuarios y contexto

El proyecto está pensado principalmente para personas que tienen plantas en sus casas y que se ausenten por largos periodos de tiempo de sus casas.
El problema ocurre principalmente en el contexto doméstico, donde las plantas requieren cuidados constantes pero a veces el usuario no puede estar presente para revisarlas, es por esta razón que queremos seguir investigando y realizando pruebas con sensores para comprobar si la medición de humedad puede ser una forma efectiva de abordar este problema.
